Decision path

One small decision before each task.

01 / RESPECT

Your choice wins

An explicit model selection skips classification. Risk floors protect high-stakes tasks when no model is specified.

02 / REUSE

Rules and cache

Local rules classify routine requests. Equivalent requests reuse a 24-hour cached decision without a network call.

03 / ESCALATE

Local models first

Ambiguous tasks can use PAW or a local System One server such as CLM or Kev, then optional Jev. Rust policy validates the result.

Install

Built in Rust. Ready for your CLI.

Edit the sample model IDs for your subscription or API account, then route a task or launch a new noninteractive session.

git clone https://github.com/alphaonedev/ai-router.git
cd ai-router
cargo build --release
./target/release/ai-router run claude --task 'Summarize this function' --offline
./target/release/ai-router run codex --task 'Debug a race condition' --offline
./target/release/ai-router run grok --task 'Implement a new feature' --offline
./target/release/ai-router openrouter-models

Add --interactive to launch a new interactive session. Use route-json for machine-readable integration, --dry-run to inspect a launch, and dashboard for a local live observatory.

Structured context

Use TOON where it earns its place.

The Rust TOON converter roundtrips JSON and keeps the smaller byte representation by default. Measure provider token usage before treating byte reduction as token savings.

./target/release/ai-router toon --input structured-context.json > context.txt
The target

50%+ compute regain is a goal to prove.

Current status: all three CLI launch paths tested. No production workload has established 50% savings. A representative labeled comparison must count router overhead, retries, quality, and actual provider usage before this claim is made.

The sample evaluation checks under-routing and over-routing; the savings command checks compute regain with quality parity. A localhost dashboard shows routing decisions as they arrive. The project README explains how to compare baseline and routed tasks at equal quality, including subscription quota rather than only API spend.
